## តើវាជាអ្វី

OmniRoute ចុះបញ្ជី provider ចំនួន 376 ដោយរួមមាន catalog entry ចំនួន 155 ដែលបានសម្គាល់ថា **free/no-auth**
(no-auth,
free-tier OAuth ឬ free-tier API key — សូមមើល
[មគ្គុទ្ទេសក៍ Free Tiers](../getting-started/FREE-TIERS-GUIDE.md) និង
[ថត Free Tiers](../reference/FREE_TIERS.md) ទាំងមូល)។ ចំណុចដែលត្រូវប្រយ័ត្ន៖ free provider នីមួយៗ
មានគុណភាពម៉ូដែលខុសៗគ្នាខ្លាំងណាស់។ no-auth provider ដែលផ្តល់ frontier model
មានប្រយោជន៍ច្រើនជាងអ្វីដែលផ្តល់ small legacy model ច្រើន។

**Free Provider Rankings** ឆ្លើយសំណួរ "**តើ free provider ណាដែលផ្តល់ម៉ូដែលល្អបំផុតដល់ខ្ញុំ?**"
ដោយភ្ជាប់ catalog របស់ free provider នីមួយៗទៅនឹង **ពិន្ទុគុណភាពដែលប្រមូលពីសហគមន៍** ពី
**Arena AI leaderboard** (human-preference ELO ដែលជាគំនិតដូចគ្នានឹង
LMArena chatbot arena)។ បន្ទាប់មក provider ទាំងនេះត្រូវបានចំណាត់ថ្នាក់តាមកម្លាំងនៃ
**ម៉ូដែល free ល្អបំផុត** របស់ខ្លួន។

ការចំណាត់ថ្នាក់ត្រូវបានគណនាពីប្រភពពិតប្រាកដចំនួនបី៖

1. បញ្ជី free-provider — `NOAUTH_PROVIDERS` បូករួមនឹង entry របស់ `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` ដែលបានដាក់ស្លាក `hasFree`
   (`src/shared/constants/providers.ts`)។
2. catalog ម៉ូដែលរបស់ provider នីមួយៗពី provider registry
   (`open-sse/config/providerRegistry.ts`)។
3. ពិន្ទុ task-fit ដែលបានបង្កើតពី ELO ដែលរក្សាទុកក្នុងតារាង DB `model_intelligence`
   ដោយ Arena ELO sync engine (`src/lib/arenaEloSync.ts`)។

ឡូហ្ស៊ិក join ស្ថិតនៅក្នុង `src/lib/freeProviderRankings.ts`។

### API endpoint

ទំព័រនេះដំណើរការដោយមាន endpoint អានជាសាធារណៈនៅពីក្រោយ
(`src/app/api/free-provider-rankings/route.ts`)៖

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

ប៉ារ៉ាម៉ែត្រសំណួរ (បានផ្ទៀងផ្ទាត់ដោយ Zod)៖

| ប៉ារ៉ាម៉ែត្រ | ប្រភេទ | លំនាំដើម | កំណត់សម្គាល់                                                                                                       |
| ------------ | ------ | -------- | ------------------------------------------------------------------------------------------------------------------ |
| `category`   | string | (គ្មាន)  | មួយក្នុងចំណោម `default`, `coding`, `review`, `documentation`, `debugging`។ កុំបញ្ចូល ដើម្បីទទួលបានចំណាត់ថ្នាក់រួម។ |
| `limit`      | number | `50`     | ត្រូវបានកម្រិតឱ្យស្ថិតក្នុងចន្លោះ `1–100`។                                                                         |

ទម្រង់ response៖

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` គឺជាតម្លៃ Arena ELO ដើម ខណៈដែល `score` គឺជាតម្លៃភាពសមស្របនឹងកិច្ចការដែលបានធ្វើឱ្យមានស្តង់ដារ
(សូមមើលខាងក្រោម)។ អ្នកផ្តល់សេវាដែលគ្មានម៉ូដែលមានពិន្ទុ ត្រូវបានដកចេញពី response។

## របៀបដំណើរការរបស់ពិន្ទុ

### ប្រភព៖ តារាងចំណាត់ថ្នាក់ Arena AI

ម៉ាស៊ីនធ្វើសមកាលកម្ម Arena ELO (`src/lib/arenaEloSync.ts`) ទាញយកតារាងចំណាត់ថ្នាក់ពីរ — `text`
និង `code` — ពី API តារាងចំណាត់ថ្នាក់ Arena AI
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`)។ នៅពេល API នោះមិនត្រឡប់តារាងដែល
អាចប្រើបាន ម៉ាស៊ីននឹងប្តូរទៅប្រើ `lmarena-ai/leaderboard-dataset` ផ្លូវការនៅលើ
Hugging Face datasets-server (`src/lib/arenaEloHfSource.ts`, CC-BY-4.0; `overall` → `text`,
`coding` → `code`) ជំនួសវិញ; `GET /api/intelligence/sync` រាយការណ៍ `activeSource`, `lastError` និង
`lastFailedAt`។ ធាតុនីមួយៗក្នុងតារាងចំណាត់ថ្នាក់
មានឈ្មោះម៉ូដែល អ្នកផ្គត់ផ្គង់ `score` ELO ចន្លោះទំនុកចិត្ត និងចំនួនសន្លឹកឆ្នោត។

ប្រភេទក្នុងតារាងចំណាត់ថ្នាក់ត្រូវបានផ្គូផ្គងទៅនឹងប្រភេទកិច្ចការរបស់ OmniRoute៖

| តារាងចំណាត់ថ្នាក់ Arena | ប្រភេទកិច្ចការរបស់ OmniRoute                      |
| ----------------------- | ------------------------------------------------- |
| `text`                  | `default`, `review`, `documentation`, `debugging` |

### ការធ្វើឱ្យមានលក្ខណៈស្តង់ដារ (ពិន្ទុសមស្របនឹងកិច្ចការ)

ពិន្ទុ ELO ដើមត្រូវបានធ្វើឱ្យមានលក្ខណៈស្តង់ដារតាមតារាងចំណាត់ថ្នាក់នីមួយៗ ទៅជា **តម្លៃសមស្របនឹងកិច្ចការក្នុង `[0.4, 0.98]`**៖

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

ពិន្ទុនេះមិនដែលឈានដល់ `0` ឬ `1` ទេ ដោយទុកចន្លោះសម្រាប់ការកំណត់ជំនួសរបស់អ្នកប្រើ។ នេះជា
វាល `score` ដែលអ្នកឃើញក្នុងការឆ្លើយតបរបស់ API និងស្លាកដែលបង្ហាញនៅលើផ្ទាំងគ្រប់គ្រង។
